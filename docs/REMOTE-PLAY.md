# 通过虚拟局域网与异地朋友玩

ZeroTier 等工具能让双方设备加入一个虚拟局域网。本项目仍然运行在房主电脑，不需要部署公网服务器；网页不会自动安装客户端、建立 VPN、授权设备或改防火墙。

## 准备

1. 双方自行从 [ZeroTier 官方下载页](https://www.zerotier.com/download/)安装对应设备客户端。官方提供 Windows、macOS、Linux、Android、iOS 等平台版本
2. 房主依照[官方入门指南](https://docs.zerotier.com/start/)建立私有网络，把网络 ID 通过私人渠道给朋友
3. 双方设备加入该网络，网络创建者在控制台逐一核对并授权可信设备。新控制台操作见 [Networks 文档](https://docs.zerotier.com/networks/)
4. 查看房主电脑在该虚拟网络内的 managed IP。不要把公网 IP 当成虚拟网络 IP

官方平台、套餐与免费额度会变化，请以[官网](https://www.zerotier.com/)当前说明为准；本项目不承诺固定免费节点数。

## 开始对弈

1. 房主运行 `npm start`，打开页面并创建一个房间
2. 朋友在自己的浏览器打开 `http://房主虚拟IP:8000`
3. 点「加入房间」。如果只有一个可加入房间，不必填写房间码；如果有多个，输入想加入的房间码
4. 也可分享 `http://房主虚拟IP:8000/?room=房间码` 自动填写指定房间
5. 房主电脑、Node 服务和两端虚拟网络客户端须一直在线；手机端按系统要求保持 VPN 连接。服务器重启会清空房间，结束前请导出棋谱 JSON

这是熟人远程联机，不是陌生人匹配服务。房间码是选择对局的标识，不是完整安全边界；角色在加入时认领，重连令牌只保留在自己的浏览器 tab session 中。

## 最小权限与排障

- 仅授权可信设备，不要公开网络 ID、私有邀请和角色重连凭据
- 默认 `npm start` 监听全部网卡。更窄的范围可用 `HOST=房主虚拟IP npm start`（Windows PowerShell：`$env:HOST='房主虚拟IP'; npm start`），只监听该接口
- 如果系统弹出防火墙提示，按需仅允许可信虚拟网卡 / 网络访问游戏 TCP 8000。不要关闭整个防火墙，也不要配置路由器公网端口转发
- 不需要为本游戏开启全局默认路由、DNS 接管或其他无关网络权限
- 不要把 AI 桥接端口暴露在公网。默认桥接仅监听本机；人机模式由房主同屏页面使用即可
- 连不上时先检查双方在线、设备已授权、虚拟 IP 正确、端口与绑定地址一致，再依据官方指南排查网络。校园 / 企业设备可能受策略限制，不要绕过组织的访问限制
- 首版未验证真实跨地域、iOS/Android、企业网和移动网络组合；可达性取决于虚拟网络工具及实际网络环境
