AI 控制与分析
游戏规则与原型边界

本地双人围棋：9 / 13 / 19 路，禁自杀，全历史局面同形禁着（停一手例外），双方连续停一手进入中国式面积计分。贴目开局可设，默认 7.5。不提供自动死活判定

黑白各有独立轮次，冻结自己的待办叶集合，可自由选择其中轮到自己颜色的一条。对手可立即回应，但自己必须处理完本轮全部待办，才能再回到已操作叶。当前玩家可以回到本条未终局时间线的自己待行历史节点，落下不同一手；原线保留，新旧线权重各半。分叉代替旧线本轮普通着，旧线待行方不变，新线加入双方各自的下一轮；分叉时对手在旧源叶尚未使用的本轮机会顺延，避免双方分叉互等。黑白棋子标识谁可下，红色与文字标示等待。已存在的历史前缀 + 出边不可重复分叉。两次停一手后不能再分叉，争议可续弈

开局可设分叉权重门槛，默认 1/512。父叶权重等于或低于门槛时不能再分叉，但可继续落子；例如门槛 1/4 时，1/2 分成两个 1/4 后都不能再分。不限制模式不设权重、次数或深度上限，仍受设备性能限制。相同局面、不同历史视为不同时间线。实际胜盘权重超过 50% 即锁定胜利，余下棋局可继续完成；全结束且没有一方过半为整体平局

支持离线同屏、局域网、远程朋友房间和兼容服务上的匿名远程匹配。无需账号，无聊天或内置 AI。AI 协议仅供开发者接入；分析胜率不等于比赛结果。局域网 HTTP 不加密，请仅用于可信网络，不要转发路由端口

和异地朋友玩：虚拟局域网（例如 ZeroTier）

网页本身不能加入虚拟网络。双方先从 ZeroTier 官网安装各设备客户端（包括 Windows、Linux、Android、iOS），由网络创建者建立私有网络，再让双方设备加入并逐一授权。按官方入门教程操作；套餐额度以官网当期说明为准。

房主在电脑运行本项目，保持电脑、虚拟网络和服务在线。朋友在浏览器打开 http://房主的虚拟网络IP:8000，点加入房间；只有一个可加入对局时无需输入码，多局才需选择房间码。也可由房主分享带 ?room=房间码 的地址。

仅授权可信设备，尽量只开放对应虚拟网卡的游戏端口。不要关闭防火墙，不需要开启默认路由或修改 DNS；不要将游戏端口或 AI 桥接端口裸露到公网。这是熟人远程联机，不是自动匹配服务。完整说明见仓库 docs/REMOTE-PLAY.md。

静态网页、AI 与联机后端说明

GitHub Pages 托管此网页，默认同屏双人可用。远程朋友房间使用独立的 HTTPS 房间服务，需双方选择同一服务并共享房间码；匿名匹配需要房间服务声明支持匹配功能。也可自行运行仓库的 Node 服务，并直接打开房主的局域网或虚拟局域网地址。此网页不运行 KataGo。

公开 HTTPS 页面连接 HTTP / WS 私有网络可能被混合内容、本地网络权限或 CORS 限制。不要关闭浏览器安全保护；本地 KataGo 也优先从本地 Node 页面使用。自行部署的 HTTPS provider 需匹配本项目协议并正确配置 CORS，不要把密钥写进网页或地址。

实验剪枝与补偿规则

开局可选择不剪枝、认输剪枝或贴目补偿剪枝。轮到当前叶时，用历史滑块选择一个非根历史节点，点击剪除：目标是该完整历史前缀的全部后代叶，不能含已结算后代，也不能剪掉所有未结算叶。

认输剪枝将整棵目标子树的实际权重判给对手并归档。贴目模式以子树总权重 W 计算补偿 ceil(2×C×W)/2 目；黑方剪则增加白贴目，白方剪则减少，应用到全部剩余未结算叶。已结算叶冻结，剩余未结算权重按比例归一化。场级账本不可通过回到旧历史撤销，归档路线不能复活。

贴目模式最低新生叶权重自动取不低于 0.5/C 的最小 2 的负整数次幂档。例如 C20 为 1/32，而非 1/40。剪枝本身须满足原始 C×W≥0.5，不能靠向上取整绕过。补偿是实验定价，不等价于胜率，也不保证反复剪枝 / 分叉最终停止。
